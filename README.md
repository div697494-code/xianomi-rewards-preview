# Xianomi rewards preview

A static, responsive concept landing page for the Xianomi project.

## Preview
Open `index.html` in a browser or enable GitHub Pages for this repository.

## What’s included
- Responsive home page with short concept/about copy and English/Chinese greeting touches.
- Original CSS illustrations for a phone, wearable, and smart-home device. They are placeholders, not photos or actual product representations.
- A non-functional “Joining opens later” call to action. This page does not collect personal details, accept payments, or promise rewards.
- Clear disclosure that this is an independent concept and is not affiliated with or endorsed by Xiaomi Corporation.

## Image use
The screenshots supplied in chat are search-result screenshots, not clean product assets. This preview uses original CSS artwork rather than cropping or embedding those screenshots. If you have rights to use product photography, replace the illustrations with approved image files. Xiaomi’s official Nigeria site is https://www.mi.com/ng/; check permissions before using its logos or product images.
